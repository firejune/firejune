## 🛠 Tools that spun out of the game

Building a game on pure web tech means building the missing tools too — most of them designed so AI agents can use them and verify their own work.

- [**spine-html**](https://github.com/firejune/spine-html) — Spine skeletal animation rendered as plain DOM: one CSS matrix per slot, no canvas for the rigid tier
- [**rigc**](https://github.com/firejune/rigc) — rig compiler for Spine: declarative rig specs in, Spine 4.3 skeleton data out, verified by a spine-core round-trip
- [**byteguard**](https://github.com/firejune/byteguard) — Vite plugin that encodes JS bundles into binary format for casual source code protection
- [**headerless**](https://github.com/firejune/headerless) — strips format-defining header fields from binary assets at build time; not encryption, not DRM
